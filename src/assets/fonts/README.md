`manrope-latin-700.ttf` is a static 700-weight subset of the Manrope font used by `next/font/google` in this project, restricted to U+0020–U+007E for the existing English Open Graph copy. It was produced from the cached Latin WOFF2 using fontTools' variable-font instancer and subsetter. This file is read only by the server image generator; it is not a browser font download.

Original project: https://github.com/googlefonts/manrope
License: SIL Open Font License 1.1, reproduced in `OFL.txt` from https://github.com/google/fonts/blob/main/ofl/manrope/OFL.txt.

If the Open Graph copy gains characters outside ASCII, extend the subset before using them.
